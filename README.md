# Java Server Program

## Overview

The Java Server Program is a Java project exploring server-side application development and the management of data associated with users, rooms, and messages.

The project provides an opportunity to explore how application components work with structured data in a server-oriented environment.

## Technologies

- Java
- IntelliJ IDEA

## Project Structure

- `src/` — Java source code.
- `users.txt` — User-related data.
- `rooms.txt` — Room-related data.
- `messages.txt` — Message-related data.

## Getting Started

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Configure a compatible Java Development Kit (JDK).
4. Locate the main application class and run its `main` method.
5. Ensure that the required data files are available in the locations expected by the application.

## Learning Outcomes

This project provided practical experience with Java programming, organizing application data, and exploring server-side software concepts.
